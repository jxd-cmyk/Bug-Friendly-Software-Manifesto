# Manifesto

After 42 years of working with computers, I know what the three fundamental characteristics of good software are:

- simplicity *(no dozens of unnecessary features)*
- lightweight *(doesn’t strain memory, the processor, or the user)*
- functional design *(the application’s front end is designed for usability, not for show)*

In line with this, I’ve built a software suite that covers the basic functions of offline computer use. It’s so easy to use that it couldn’t be any simpler. This software will run just fine even on a computer that’s running a local LLM and currently exporting a video.


**CZ**

# Manifest

Po 42 letech života s počítači vím, jaké jsou tři základní vlastnosti dobrého software:

- jednoduchost *(nejsou přítomny desítky zbytečných funkcí)*
- lehkost *(nezatěžuje paměť, procesor ani uživatele)*
- účelový vzhled *(frontend aplikace není na efekt, ale na obsluhu)*

V souladu s tím jsem vybudoval balíček software, který pokrývá základní funkce offline užívání počítače. Ovládá se tak jednoduše, že jednodušeji to už nejde. Software, které ochotně poběží i na computeru, kde běží místní LLM a právě exportuje video.
